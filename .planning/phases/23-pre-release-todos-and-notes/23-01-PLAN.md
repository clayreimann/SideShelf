  <action>
**Per D-01/D-02:** The splash screen must stay visible until `AuthProvider.initialized` is `true`. The challenge is that `AuthProvider` is a child of `RootLayout`, so `RootLayout` cannot call `useAuth()`.

**In `src/providers/AuthProvider.tsx`:**

1. Export a module-level callback mechanism. Add at the top of the file:
   ```typescript
   let _onAuthInitialized: (() => void) | null = null;
   export const authInitializedPromise = new Promise<void>((resolve) => {
     _onAuthInitialized = resolve;
   });
   ```
2. In the `useEffect` where `setInitialized(true)` is called, also call `_onAuthInitialized?.()` immediately after.

**In `src/app/_layout.tsx`:**

1. Import `authInitializedPromise` from `@/providers/AuthProvider`.
2. Modify `onLayoutRootView` to await both conditions:
   ```typescript
   const onLayoutRootView = useCallback(async () => {
     if (fontsLoaded || fontsError) {
       await authInitializedPromise;
       await SplashScreen.hideAsync();
     }
   }, [fontsLoaded, fontsError]);
   ```
3. Do NOT add `initialized` to the deps array of the callback — the promise-based approach avoids needing it as a React dependency.
   </action>

**Per D-04/D-07:** Replace the destructive `router.replace("/login")` with a modal push.

**In `src/app/(tabs)/_layout.tsx`:**

1. Find the `useEffect` that checks `loginMessage && !isAuthenticated` and calls `router.replace("/login")`.
2. Replace `router.replace("/login")` with `router.push("/login")`. The login screen already has `presentation: "formSheet"` configured in `_layout.tsx`, so this will present as a dismissible sheet.
3. **Per D-05:** Add a `headerLeft` button on all tab Stack.Screens when `loginMessage` is truthy and `!isAuthenticated`. The button calls `router.push("/login")`. Implementation:
   - Create a `tokenExpiredHeaderLeft` component or inline function that renders a small button (e.g., a key/lock icon with text "Sign In") and calls `router.push("/login")` on press.
   - Apply it via `screenOptions` on the `Tabs` component: when `!isAuthenticated && loginMessage`, set `headerLeft: () => <TokenRefreshButton />`. When `isAuthenticated`, set `headerLeft: undefined`.
   - Use `MaterialIcons` name `"login"` or `"vpn-key"` for the icon. Keep it subtle — just icon + "Sign In" text, tinted with the theme accent color.

**Per D-06:** After successful login via modal, the user must stay on the same screen.

**In `src/app/login.tsx`:**

1. Find the `useEffect` that checks `initialized && isAuthenticated` and calls `router.replace("/")`.
2. Replace with: `if (router.canGoBack()) { router.back(); } else { router.replace("/"); }`.
   - When presented as a modal (formSheet), `canGoBack()` is `true` — `router.back()` dismisses the sheet, returning to the previous screen.
   - When presented as initial login (no back stack), `canGoBack()` is `false` — `router.replace("/")` navigates to tabs as before.
3. The `headerLeft` button in tabs layout disappears automatically because `isAuthenticated` becomes `true` after successful login, which clears the `screenOptions.headerLeft`.
   </action>
