**Per D-14 — Fix flicker during intermediate states:**

The coordinator passes through LOADING/BUFFERING states where `isPlaying` is `false`. To prevent the icon from flickering back during these transitions:

- Only clear `pendingIsPlaying` when NOT in a loading state:
  ```typescript
  useEffect(() => {
    if (pendingIsPlaying !== null && isPlaying === pendingIsPlaying && !isLoadingTrack) {
      setPendingIsPlaying(null);
    }
  }, [isPlaying, pendingIsPlaying, isLoadingTrack]);
  ```
- This ensures the optimistic state holds through LOADING/BUFFERING transitions until the final PLAYING/PAUSED state arrives.
