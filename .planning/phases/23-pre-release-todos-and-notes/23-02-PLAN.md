**Per D-08 — Fix coordinator LOAD_TRACK short-circuit:**

In `src/services/coordinator/PlayerStateCoordinator.ts`, find the short-circuit block at ~line 1194-1202. When `startPosition` is present in the LOAD_TRACK payload AND differs from the current position, the short-circuit must dispatch SEEK before PLAY:

```typescript
if (wasActivelyPlayingOrPaused && event.payload.libraryItemId === currentTrack?.libraryItemId) {
  const startPos = event.payload.startPosition;
  const currentPos = useAppStore.getState().player.position;
  if (startPos !== undefined && Math.abs(startPos - currentPos) > 1) {
    log.info(`[Coordinator] Short-circuit with seek: ${currentPos} -> ${startPos}`);
    dispatchPlayerEvent({ type: "SEEK", payload: { position: startPos } });
  }
  // Thread meta through so skipSmartRewind reaches executePlay
  dispatchPlayerEvent({ type: "PLAY" }, meta ?? { source: "native_player" });
  return;
}
```
